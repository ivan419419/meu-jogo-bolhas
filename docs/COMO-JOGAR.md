# Como jogar o protótipo

1. Abra `index.html` no Chrome.
2. Mova o mouse ou arraste o dedo para ajustar a mira; a linha pontilhada inclui o ricochete nas laterais.
3. Clique ou toque no tabuleiro para atirar.
4. Conecte três ou mais bolhas da mesma cor. Bolhas que perderem a ligação com o teto caem.
5. Use **Trocar** para alternar entre a bolha atual e a próxima. **Jogar de novo** reinicia a partida.

A página funciona offline: a lógica TypeScript é compilada e embutida no próprio HTML.
